## Overview

The **IIS pipeline** is a domain-agnostic, information-theoretic framework that
characterizes the *order structure* of statistical dependence in multivariate data.
Rather than asking "are these variables dependent?", it asks:

> **At what interaction order does dependence live — pairwise, three-way,
> four-way, or higher?**

The pipeline produces two complementary outputs:

| Output | What it measures |
|--------|-----------------|
| **IIS fingerprint** (p₂, p₃, p₄, p₅) | *Shape* — which interaction orders carry dependence |
| **Architecture strength** (A_total, Z_total) | *Magnitude* — how much total dependence exists |

Reading both together prevents a normalized fingerprint from misrepresenting
datasets with near-zero total dependence (e.g. independence nulls).

## Quickstart

```python
import pandas as pd
from src import run_iis, iis_entropy

# ── your data ────────────────────────────────────────────────────
df = pd.read_csv("your_data.csv")   # samples × variables

# ── build a type-matched null (column permutation) ───────────────
import numpy as np
rng      = np.random.default_rng(0)
null_df  = df.copy()
for col in null_df.columns:
    null_df[col] = rng.permutation(null_df[col].values)

# ── run null first ───────────────────────────────────────────────
_, null_mass, _, _, _ = run_iis(null_df, is_discrete=False, null_mass=None)

# ── run pipeline on your data ────────────────────────────────────
iis, raw_mass, corrected_mass, entropy_table, mobius = run_iis(
    df,
    is_discrete=False,    # True for integer/binary data
    null_mass=null_mass,
    verbose=True
)

print("IIS fingerprint :", iis)
print("Architecture entropy :", iis_entropy(iis))
print("Total corrected mass :", sum(corrected_mass.values()))
```

## Key API

| Function | Module | Description |
|---|---|---|
| `run_iis(df, is_discrete, null_mass)` | `src.pipeline` | Full pipeline → IIS fingerprint, masses, entropy table, Möbius coefficients |
| `iis_entropy(iis)` | `src.pipeline` | Architecture entropy H_IIS |
| `mobius_inversion(entropy_table)` | `src.mobius` | Möbius inversion on the Boolean subset lattice |
| `architecture_mass(mobius)` | `src.mobius` | Aggregate \|M(S)\| by order → A₂–A₅ |
| `knn_entropy(X, k)` | `src.estimators` | Kozachenko–Leonenko k-NN entropy (continuous) |
| `discrete_entropy(X)` | `src.estimators` | Plugin entropy estimator (discrete) |
| `copula_transform(df)` | `src.estimators` | Rank-based copula normalization |

## Extending the pipeline

- **Different entropy estimator:** Edit `src/estimators.py` only.
  The Möbius math and normalization are unchanged.
- **Different interaction orders:** Pass `orders=(2,3,4)` to `run_iis`.
- **Larger p:** The current implementation is exact (all 2^p subsets).
  For p > 10, subset sampling is recommended — contact the author for
  the scalable variant described in the dissertation.
